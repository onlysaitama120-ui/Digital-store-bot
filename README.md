# 🛒 Digital Store Bot

A Discord bot for managing and selling digital products.

## ✨ Features

- 🛍️ **Product Management** - Add, edit, and remove digital products
- 💳 **Payment Integration** - Handle transactions seamlessly
- 🔐 **Secure Delivery** - Automated product delivery after purchase
- 📊 **Sales Tracking** - Monitor your store performance

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- Discord Bot Token

### Installation
```bash
git clone https://github.com/onlysaitama120-ui/Digital-store-bot.git
cd Digital-store-bot
npm install
```

### Configuration
```bash
cp .env.example .env
# Edit .env with your Discord bot token
```

### Run
```bash
npm start
```

## 📝 Commands

| Command | Description |
|---------|-------------|
| `!addproduct` | Add a new product |
| `!listproducts` | View all products |
| `!buy <product>` | Purchase a product |
| `!sales` | View sales statistics |

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Library:** Discord.js
- **Database:** SQLite / JSON
